## 评价口径

任务、原代码、独立验收和预算在付费执行前冻结。先运行原生 Agent；原生功能全对时跳过增强，保留这个结果。存在真实缺口且有适用项目知识时，再运行同一任务的增强对照。外部验收和原有测试保护独立执行，不修改冻结标准迎合结果。

增强记录实际 Skill 读取、修改顺序、检查覆盖和正式 Verify。未知服务等级和调用次数如实记录，CLI 进程启动数不冒充模型 API 请求数。单例百分比不冒充总体提升率。
